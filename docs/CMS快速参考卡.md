## 🖼️ 图片上传

### 支持格式

- JPG, PNG, GIF, WebP, AVIF

### 大小限制

- 管理员上传: 最大10MB
- 普通上传: 最大20MB

### 上传方式

1. **点击上传**: 选择文件上传
2. **拖拽上传**: 拖拽文件到上传区
3. **粘贴上传**: 在编辑器中直接粘贴
4. **URL输入**: 输入外部图片链接

## 📝 内容发布流程

### 标准步骤

1. **选择内容类型** → 进入对应管理页面
2. **创建内容** → 点击"创建"或"添加"按钮
3. **填写基本信息** → 标题、描述、分类等
4. **编辑内容** → 使用富文本编辑器
5. **上传图片** → 添加相关图片和媒体
6. **预览检查** → 确认内容格式正确
7. **设置状态** → 选择草稿或发布
8. **保存发布** → 完成内容发布

### 状态说明

- **草稿**: 未发布，仅管理员可见
- **已发布**: 公开可见
- **已归档**: 不再显示但保留数据

## 🔧 常用设置

### 图片规格建议

- **新闻封面**: 1200x630px
- **产品图片**: 800x600px
- **Banner图**: 1920x1080px
- **Logo**: 200x200px (PNG透明背景)

### SEO优化

- **标题**: 30-60字符，包含关键词
- **描述**: 120-160字符，简洁概括
- **图片Alt**: 描述性文字，有助于SEO

## 🚨 紧急操作

### 快速撤销

- **撤销编辑**: Ctrl+Z
- **恢复草稿**: 在编辑页面选择之前保存的版本
- **紧急下线**: 将状态改为"草稿"或"归档"

### 故障排除

1. **刷新页面**: F5或Ctrl+R
2. **清除缓存**: Ctrl+Shift+Delete
3. **重新登录**: 退出后重新登录
4. **联系支持**: support@lgjh.com
