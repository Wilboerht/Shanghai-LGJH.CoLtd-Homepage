## 📝 更新规范

### 版本号规则
- **主版本号**: 重大功能变更或架构升级
- **次版本号**: 新功能添加或重要更新
- **修订版本号**: 错误修复或小幅改进

### 更新类型
- **新增内容**: 添加新的章节或功能说明
- **功能更新**: 现有功能的变更或优化
- **技术改进**: 文档格式、结构或技术方面的改进
- **错误修复**: 修正文档中的错误或不准确信息

### 更新流程
1. 记录系统功能变更
2. 更新相关文档内容
3. 重新截图更新界面
4. 测试文档完整性
5. 更新版本号和日期
6. 发布新版本文档
