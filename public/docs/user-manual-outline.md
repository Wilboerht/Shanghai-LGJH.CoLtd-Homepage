## 🎨 设计规范

### 文档样式
- **字体**: 微软雅黑 (正文12pt, 标题14-18pt)
- **颜色**: 主色调蓝色 (#3b82f6), 辅助色灰色
- **页面**: A4纸张, 2cm边距
- **页眉**: 包含章节名称和页码
- **页脚**: 包含版权信息和版本号

### 截图规范
- **分辨率**: 1920x1080 或更高
- **格式**: PNG (保持清晰度)
- **标注**: 使用红色箭头和文字说明
- **尺寸**: 适合A4页面宽度

## 📝 内容编写指南

### 写作风格
- 使用简洁明了的语言
- 采用步骤化的操作说明
- 提供实际的操作示例
- 包含常见问题解答

### 操作步骤格式
```
步骤1：点击左侧导航菜单中的"内容管理"
步骤2：选择"产品管理"子菜单
步骤3：点击"新增产品"按钮
步骤4：填写产品基本信息...
```

### 注意事项格式
```
💡 提示：建议在编辑内容前先保存草稿
⚠️ 注意：删除操作不可恢复，请谨慎操作
❌ 错误：如果出现此错误，请检查网络连接
```
