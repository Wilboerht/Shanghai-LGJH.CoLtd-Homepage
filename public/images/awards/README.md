请将您的荣誉奖项图片放置在此目录中，并按以下要求命名：

- `digital-transformation-2024.jpg` - 2024数字化转型十大杰出企业
- `fortune-500-2024.jpg` - 2024年《财富》中国500强第186位
- `data-privacy-solution-2024.jpg` - 2024年度最佳数据私有化解决方案
- `brand-value-australia-2024.jpg` - 2024年度澳大利亚上市公司品牌价值TOP100
- `new-economy-top100-2023.jpg` - 2023新经济企业TOP100
- `digital-benchmark-2023.jpg` - 2023数字化转型行业标杆企业奖
- `investment-value-2023.jpg` - 最具投资价值上市公司
- `cloud-computing-2023.jpg` - 中国上市公司数智化云计算企业
- `data-governance-dama-2023.jpg` - DAMA中国数据治理优秀实践奖

### 图片规格建议

- **格式**: JPG, PNG, WebP
- **分辨率**: 建议 800x600 或更高
- **宽高比**: 3:4 (奖杯、奖牌通常为竖版)
- **文件大小**: 建议小于 2MB
- **质量**: 清晰可读，确保奖项内容清楚可见

### 图片优化建议

1. **压缩图片**: 使用工具如 TinyPNG 或 ImageOptim 压缩
2. **统一尺寸**: 保持奖项图片尺寸一致性
3. **清晰度**: 确保奖项文字和标识清晰可见
4. **背景**: 建议使用白色或浅色背景，突出奖项主体

### 奖项类型分类

- **管理奖项**: 企业管理相关奖项
- **数字化转型**: 数字化转型领域奖项
- **企业排名**: 各类企业排行榜
- **技术创新**: 技术创新和产品奖项
- **品牌价值**: 品牌价值评估奖项
- **投资价值**: 投资价值相关奖项
- **数据治理**: 数据管理和治理奖项

### 备用方案

如果某个奖项图片暂时不可用，组件会显示占位符图片。您可以随时添加或更新奖项图片。

### 更新奖项信息

如需修改奖项标题、描述、年份或分类，请编辑 `src/components/sections/awards.tsx` 文件中的 `awards` 数组。
