# 团队成员头像管理

这个目录用于存放研究团队成员的头像图片。

## 🎯 快速开始

### 1. 添加新头像
1. 将头像图片文件放入此目录
2. 按照命名规范重命名文件
3. 在CMS中编辑研究项目，添加头像URL
4. 刷新页面查看效果

### 2. 使用CMS管理
- 访问 `/admin/media/avatars` 查看所有可用头像
- 在研究编辑页面使用头像选择器
- 复制头像URL到作者信息中

## 📋 图片命名规范

头像图片应该按照以下格式命名：
```
姓名-职位.扩展名
```

### 示例：
- `zhang-dr.jpg` - 张博士
- `li-researcher.jpg` - 李研究员
- `wang-engineer.jpg` - 王工程师
- `chen-dr.jpg` - 陈博士
- `zhao-dr.jpg` - 赵博士
- `sun-engineer.jpg` - 孙工程师
- `li-chief.jpg` - 李总工
- `wang-architect.jpg` - 王架构师
- `zhang-wei.jpg` - 张伟
- `li-ming.jpg` - 李明
- `wang-fang.jpg` - 王芳
- `chen-qiang.jpg` - 陈强

### 命名规则：
- 使用小写字母
- 用连字符 `-` 分隔
- 避免使用中文和特殊字符
- 保持简洁明了

## 📐 图片要求

| 属性 | 要求 | 说明 |
|------|------|------|
| **格式** | JPG, PNG, WebP | 推荐使用 JPG 格式 |
| **尺寸** | 200x200 像素或更高 | 保证清晰度 |
| **比例** | 1:1 (正方形) | 确保显示效果 |
| **文件大小** | < 500KB | 优化加载速度 |
| **背景** | 纯色或简洁背景 | 突出人物主体 |

## 🎨 显示效果

### 有头像时：
- 显示真实照片
- 圆形裁剪
- 悬停效果

### 无头像时：
- 显示姓名首字母
- 主题色渐变背景
- 优雅的占位符
